# Plan: trial pianos for Tab playback (#124)

1. `scripts/build-pianos.py` (stdlib + ffmpeg): SF3 writer, Salamander builder (layers, quality,
   rate), `extract` for one preset of an SF3, `--as-program`. Pad the sample chunk to an even size:
   alphaTab's RIFF reader skips no pad byte.
2. Build A (Salamander v11, q2, 32 kHz), B (v5/v11/v16, q4, 44.1 kHz), C (FluidR3 Mono piano) into
   `public/soundfont/` as programs 120 to 122.
3. Render one passage offline with each (alphaTab's audio exporter) to check it sounds, that it
   overrides SONiVOX's preset, and to set each level.
4. `playback.ts`: `TRIAL_PIANOS`, `SOUND_LIST`; the player loads a piano's font on its first use
   (append), shows Loading, and scales the volume by its level.
5. Test: each trial font renders a note. Credits in NOTICE.md, README and the soundfont README.
6. Check in Chromium: each piano loads and plays, a switch mid-play carries on.
